## Overnight run 6, stage 2: light and dark appearance

  palettes per theme, in the working app and the wireframe (DEC-028, PRD-081,
  `.kiro/specs/appearance/`). Will approved the light direction at `5ce82b4`.

  Open WebUI frame came from the official README demo GIF. All captures stay in the ignored
  `docs/design/references/`.
- **Defects caught by the screenshots and fixed.**
  - "Dark mode" wrapped onto two lines in the desktop side bar, and the switch scrolled off
    screen on long pages such as an issue. The side bar is now sticky above 760 px, and a
    test checks both.

    hover mixed in white. It now darkens, giving 4.5:1 or more.
  - The review bar's feedback field border was 2.85:1 in the light palettes. It is now 3:1
    or more.
  - Four approved light values moved slightly so every text pair passes 4.5:1 (DEC-028).
- **Steering.** `.kiro/steering/source-boundaries.md` now names both spellings of the
  internal-tools folder, and records the visual-reference convention from DEC-026 and this
  run.

  assertion (`UV_HANDLE_CLOSING`, `src\win\async.c`) when the app closes. It happens in the
  existing `b1-electron.spec.ts` too, and the tests still pass. It looks like a teardown
  issue in Playwright's Electron driver, not Nexus (not confirmed).
- **Evidence.**

  - E2E: 57 of 57 with one skipped (the screenshot run, which needs

- **Scope.** PRD-064 and architecture 7.4: reject, then Skip or Send a reason; a correction on
  the disputed target, which supersedes the rejected change; Retry after a failure or a
  restart (DEC-029, `.kiro/specs/edit-first-journey/` Requirement 5 and task 5a).
- **Defect caught by the browser test and fixed.** After a rejection the bar moved straight
  to the next change's page, which took focus from the reason box and would have opened the

    the file). It passed five times alone. The test's hand repair now retries the rename, as
    the product's atomic write already does.
- **Limits.** Only field and note-line changes are corrected. Every run used the test double,
  so live Edit corrections remain unverified.
- **Evidence.**
