- **Defects caught by tests, all fixed.**
  - The Home page's "Notes" link and a form whose `aria-label` duplicated
    the input's name made Playwright locators ambiguous. I renamed the
    forms' accessible names ("Create a note", and so on), so screen readers
    no longer hear the same name for the form and its field.
- **Design point found while implementing.** Browser text areas turn CRLF
  into LF. Without a guard, saving a Windows-edited note would rewrite
  every line ending. The service now keeps CRLF files as CRLF.
- **Design point found while implementing.** Creating an issue writes two
  files (issues, then projects). The next key is taken from the counter and
  from the existing keys, so a crash between the two writes cannot reuse a
  key.
