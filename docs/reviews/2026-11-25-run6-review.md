  confirmation.

  read every note and returned 1,000 rows in about 0.39 to 0.58 s, before HTTP and
  rendering. Tolerable for occasional navigation; a cache or index by source revision is
  suggested if that size is representative.
- **Screen readers.** The reviewer verified keyboard selection, insertion and Undo in Edge
  and Electron, but ran no NVDA or Narrator check. What a screen reader says for the
  selected option, including its folder, is unverified. The fallback insertion's Undo is
  also unverified.
- **Electron close with an unsaved draft.** In the reviewer's Electron completion test,
  closing with the draft unsaved timed out after 90 s; with an explicit Save it passed.
  The reviewer did not establish a cause. **Kiro's reading of the source (not verified):**
  the note page cancels `beforeunload` while a draft is unsaved
  (`apps/web/src/pages/NotesPage.tsx:220`), and Electron main has no
  `will-prevent-unload` handler, so the window may refuse to close.
