# Submission checklist

The single gate for submitting Nexus. Derived from
`docs/intake/kiroween-rules-summary.md` and intake R-V and R-E items. Tick
an item only with evidence (link, file or recorded check). Will and Hein
perform publication and submission; agents prepare only.

Markers: `[ ]` not done, `[~]` partly done (say what remains), `[x]` done.

## Rules

- [ ] **Final rules recheck.** Will or Hein rereads the live
  <https://kiroween.devpost.com/rules> (and overview/FAQ) before submitting,
  compares it with the rules summary, and records any change and its date.
- [ ] Kiro credit request sent before 1 December 2026, 20:00 GMT (if wanted).

## Repository

- [ ] Public GitHub repository with all source, assets and instructions.
- [ ] Open-source licence file, shown in the repository's About section.
- [ ] Root `.kiro/` present with specs, steering and hooks; not ignored.
- [ ] `docs/licences.md` lists third-party and pre-existing work.
- [ ] Reproducible setup instructions checked on a clean machine.

## Working product

- [ ] Free working route for judges (test build and/or URL), no paid
  account, no bundled private key; synthetic sample workspace included.
- [ ] Any fixture or replay clearly labelled.
- [ ] Release checks R-V2 to R-V6 passed and recorded.
- [ ] Demonstration journey R-V1 rehearsed end to end.

## Submission materials

- [ ] Public YouTube video under three minutes, no unlicensed music or marks.
- [ ] Text description of features and functionality.
- [ ] Kiro usage write-up, drawing on journal evidence (specs, steering,
  hooks, MCP, skills).
- [ ] Category Frankenstein (and any bonus categories) selected.
- [ ] Submitted by the team Representative before 4 December 2026, 22:00 GMT.
